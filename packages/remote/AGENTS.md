# Repository guidelines

Use Simplified Chinese for user communication and English code comments. Node 24+, Rust 1.97.1. Run pnpm build, pnpm test and the relevant real Agent integration tests after changes. Run cargo fmt and cargo test for Agent changes. Never add a dependency on the Obsidian source tree. Preserve device identities and existing configuration. Use Conventional Commit subjects; do not commit secrets or real user fixture data.
